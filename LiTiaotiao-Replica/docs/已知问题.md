# 已知问题 / 局限

1. **运行载体差异（非缺陷）**
   原版李跳跳是 Android `AccessibilityService`，在真机上实时监听窗口事件并遍历无障碍节点树。
   本复刻在**无 Android SDK / 无设备**环境下，以**功能等价**的 Web 工作台替代：规则匹配与点击决策逻辑与原版一致，
   但「实时监听窗口」由「模拟器中的节点树快照」替代。逻辑可验证，载体不同。

2. **`delay` / `delay_popup` 未实际延时**
   参数已建模、可存储与导出，但引擎在单次屏幕评估中未实现毫秒级延时点击（真机用于等待动画）。
   不影响命中与点击目标的判定，仅缺少时序等待。

3. **`unite_popup_rules` 连续任务为单帧建模**
   原版的「持续任务」（如倒计时后按钮可点、自动安装）依赖多次窗口事件驱动。本引擎在**一次屏幕快照**内
   能识别 `times=0` 的检测态规则与对应的点击规则，但无法跨越多次快照推进「等待→出现→点击」的完整时序。
   模拟器可在不同快照上分别运行以演示各阶段。

4. **`|` 前缀按字面文本处理**
   官方文档仅定义 `+ - = &` 四种匹配前缀。数据中出现的 `| 跳过` 在本实现中按**模糊包含的 literal 文本**处理
   （与社区规则文件中该写法作为跳过按钮文案的实际情况一致）。如需将其定义为某种「或」语义，可在 `engine.match_condition` 扩展。

5. **坐标点击在真实设备上的约束**
   基于 `bounds` 的规则（`x1,y1,x2,y2`）依赖控件坐标，而坐标随设备/分辨率变化。社区规则库已建议避免使用纯 bounds 规则；
   本工作台如实保留该能力，但与原版一样存在设备相关性。

6. **服务端口冲突**
   默认端口 `8000` 在本机若被占用，请用 `LTT_PORT=8011 python run.py` 指定其他端口。

7. **种子数据来源**
   初始规则来自社区 `AllRules.json`（Snoopy1866/LiTiaotiao-Custom-Rules），其覆盖范围与时效以社区维护为准；
   可通过「规则导入」随时用最新官方/社区规则覆盖更新。部分应用官方已停止维护（原项目 2023-08 停更）。

8. **`search_times_popup` 实际不生效（与官方语义待确认）**
   该参数本意是「重复搜索弹窗规则 N 次」，但实现里同屏去重键（`id|action`）**跨轮复用**，
   第二轮起所有规则都会被判定为「已处理」而跳过，因此多轮搜索不产生额外点击。
   Python 与 Java 两端行为一致（对等实现），单次点击次数由规则自身的 `times` 控制。
   若确认官方语义是「同一弹窗连点 N 次」，应改为每轮重置去重键——但那会与「同屏防重复点击」冲突，故暂保持现状。

9. **`force-stop` 会清空无障碍绑定（运维注意）**
   Android 上 `am force-stop <李跳跳包名>` 会把 `secure.enabled_accessibility_services` 置空，
   服务需重新授权才能再次工作（脚本 `verify_on_device.py` 已在工作前后自动维护该设置）。
   调试时如需重启李跳跳进程，请确认 `settings get secure enabled_accessibility_services` 仍包含
   `hello.litiaotiao.app/hello.litiaotiao.app.service.LttAccessibilityService`。

10. **未编译 Android 原版 APK（仅指官方加固包）**
    官方 APK 经腾讯乐固加固（DEX 加密），静态反编译不可行，因此**未**反编译或重编译官方包。
    本项目的 Android 端是**独立重写**的完整实现（非反编译产物），已成功编译、签名并在模拟器上实测通过；
    功能依据已提取的资源、字符串、布局清单、无障碍配置与规则 JSON 还原，无伪代码与占位实现。

11. **跳过提示需要「显示在其他应用上层」权限（Android 11+ 行为）**
    原版李跳跳在每次跳过后会闪现「小兔子乖乖」提示。本复刻 v2.2.6 起以 **WindowManager 悬浮窗**实现该提示（文案对齐原版「小兔子乖乖」）
    （不用系统 Toast——`targetSdk 34` 下后台服务的 Toast 在 Android 11+ 会被系统拦截）。
    - 该悬浮窗需要 `SYSTEM_ALERT_WINDOW` 权限；未授予时提示**静默不显示**（不影响跳过本身），不崩溃；
    - 设置页「隐藏 Toast 提示」(`hide_toast`) 可彻底关闭该功能；
    - 首页在「未授权且未隐藏」时会显示「开启悬浮窗权限」引导按钮，点它跳转系统设置授权。
    - 验证环境说明：本次实现在**无模拟器/设备**的环境下以「干净构建通过 + 38 项 JVM 单测全过」为准；
      真机/模拟器上的悬浮窗显示请按 `LiTiaotiao-Android/dist/README.md` 的「如何在设备上验证跳过提示」手动确认。
