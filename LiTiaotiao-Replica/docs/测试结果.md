## 6. 全局规则 / 小程序开屏广告实测

| 场景 | 输入 | 结果 |
| --- | --- | --- |
| 小程序宿主纯图片广告（无跳过按钮） | 包名 `com.tencent.mm`，屏幕仅广告文案，`use_global=1` | 命中 `mini_program` 兜底 → 生成 **返回键** 动作，`total_clicks=1` |
| 第三方小程序包内含「跳过广告」文字 | 包名 `com.thirdparty.miniad`，节点 text=`跳过广告` | 全局关键词命中 → **点击该控件**，`total_clicks=1`（多关键词命中同一按钮已按节点去重，不再点两次） |
| 关闭全局且无应用规则 | `use_global=0` | 返回 `400`（明确提示需开启全局规则） |

> 全局规则对**所有包**生效，因此即使开屏广告以小程序 / 独立容器打开、前台包名变了，也能命中；图片类无文字广告则用「小程序宿主自动返回」兜底。
