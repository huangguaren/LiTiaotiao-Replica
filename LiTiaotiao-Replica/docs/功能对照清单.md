# 功能对照清单（与原版李跳跳）

下表逐项对照原版李跳跳（基于 APK 资源、字符串与社区规则库还原出的功能）与本复刻工作台的对应实现情况。

| # | 原版功能 | 复刻实现 | 状态 |
| --- | --- | --- | --- |
| 1 | 无障碍服务跳过开屏广告（关键词匹配） | 引擎 `keywords` 匹配 + 模拟器 | ✅ 复刻 |
| 2 | 无障碍服务关闭应用内弹窗（`popup_rules`） | 引擎 `popup_rules` 匹配与点击决策 | ✅ 复刻 |
| 3 | 匹配前缀语义：`+` 开头 / `-` 结尾 / `=` 完全 / 默认模糊包含 | `engine.match_condition` 完整实现 | ✅ 复刻 |
| 4 | `&` 多条件「且」匹配 | `match_condition` 中 `&` 拆分 | ✅ 复刻 |
| 5 | 动作：点击文本/资源 id | `resolve_action` 定位可点击控件 | ✅ 复刻 |
| 6 | 动作：`GLOBAL_ACTION_BACK`（返回键关闭弹窗） | `resolve_action` 返回 back 动作 | ✅ 复刻 |
| 7 | 动作：按坐标点击 `x1,y1,x2,y2`（含 CheckBox 状态 `,0/1`） | `is_bounds` + bounds 动作 | ✅ 复刻 |
| 8 | `times` 点击次数（0 = 仅检测） | `evaluate_screen` 按 times 生成点击动作 | ✅ 复刻 |
| 9 | `click_way_popup` 强制点击 | `force` 参数回退点击命中控件 | ✅ 复刻 |
| 10 | `search_times_popup` 多次扫描 | 外层循环 + 同屏规则去重 | ✅ 复刻 |
| 11 | `unite_popup_rules` 联合规则（连续任务） | `times=0` 检测态 + 连续任务建模 | ✅ 复刻（见已知问题） |
| 12 | `delay` / `delay_popup` 延迟点击 | 参数已建模并在导入/导出中保留 | ⚠️ 引擎暂未做实际延时（见已知问题） |
| 13 | 应用列表 / 启用 / 禁用 / 白名单 | 应用管理页 + 数据库 `enabled`/`whitelisted` | ✅ 复刻 |
| 14 | 规则导入（官方 AllRules/Basic/Extended 格式） | `/api/import` + 容错（尾随逗号） | ✅ 复刻 |
| 15 | 规则导出（回写官方格式） | `/api/export` 还原 hash→规则字符串 | ✅ 复刻 |
| 16 | 全局设置（主开关、隐藏 Toast、过滤不可见节点、反向遍历等） | 设置页 + `settings` 表，键名还原自 APK 字符串资源 | ✅ 复刻 |
| 17 | 已跳过次数统计 | `skip_logs` + 统计接口 + 首页大数字 | ✅ 复刻 |
| 18 | 包名 → 规则 hash 映射 | `Java String.hashCode` 复刻 + 社区目录反查 | ✅ 复刻 |
| 19 | 社区规则库 300+ 应用规则 | 种子导入 328 应用 / 795 条规则 | ✅ 复刻 |
| 20 | 真机 AccessibilityService 实时监听窗口事件 | 由 Web「模拟器」以节点树快照代替 | ⚠️ 等价替代（见已知问题） |
| 21 | 应用内 UI（首页/更多/设置/关于） | 高保真还原的 Web 工作台（首页/应用管理/导入/模拟器/设置/关于） | ✅ 复刻（Web 形态） |
| 22 | 全局规则（对所有应用生效） | 「全局规则」页：全局跳过关键词 + 全局弹窗规则，先于应用规则评估 | ✅ 新增 |
| 23 | 小程序 / 异包开屏广告 | 全局规则拦截（包名变化也能命中）+ 小程序宿主「找不到跳过按钮则自动返回」兜底 | ✅ 新增 |

**说明**：第 20、21 项因运行环境（无 Android SDK、无设备）采用等价替代方案，逻辑与原版完全一致，差异仅在运行载体（浏览器工作台 vs 安卓无障碍服务）。
