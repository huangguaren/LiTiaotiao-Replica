# 如何测试李跳跳的跳过效果

在雷电模拟器上验证「李跳跳是否真的能跳过广告」的完整步骤。

## 前置条件

1. 模拟器里已装 **李跳跳**（`hello.litiaotiao.app`）和**应用宝**（`com.tencent.android.qqdownloader`）。
2. 已连接 adb：`adb connect 127.0.0.1:5555`
3. 李跳跳的无障碍服务已开启（首页开关打开，并在系统设置里启用）。

验证服务是否启用：
```bash
adb shell settings get secure enabled_accessibility_services | tr ',' '\n' | grep litiaotiao
```

---

## 方法一：用测试专用 App（推荐，结果可控）

`LiTiaotiao-TestTarget` 是一个带「假广告」的测试 App：
- 开屏广告区有「跳过广告」按钮 → 命中**全局关键词**
- 「打开更新弹窗」→ 弹出「检测到更新」→ 命中注入的**弹窗规则**

```bash
# 1. 构建并安装（详见 LiTiaotiao-TestTarget/README.md）
cd LiTiaotiao-TestTarget
adb install -r app/build/outputs/apk/debug/app-debug.apk

# 2. 注入弹窗规则（hash = Java hashCode("hello.litiaotiao.testapp")）
HASH=$(python -c "import sys;sys.path.insert(0,'LiTiaotiao-Replica');from litiaotiao.hashutil import java_hashcode;print(java_hashcode('hello.litiaotiao.testapp'))")
adb shell "run-as hello.litiaotiao.app sqlite3 databases/litiaotiao.db \
  \"INSERT OR REPLACE INTO apps(hash,package,display_name,enabled,whitelisted,source,created_at,updated_at) \
   VALUES($HASH,'hello.litiaotiao.testapp','跳跳测试',1,0,'manual','2026-10-24','2026-10-24'); \
   DELETE FROM rules WHERE app_hash=$HASH; \
   INSERT INTO rules(app_hash,rule_type,match_id,action,times,sort_order) \
   VALUES($HASH,'popup','检测到更新','以后再说',1,0);\""

# 3. 启动测试 App
adb shell am start -n hello.litiaotiao.testapp/.MainActivity
```

**观察点**：开屏广告的「跳过广告」被自动点击；点「打开更新弹窗」后「以后再说」被自动点击。

---

## 方法二：用真实 App（应用宝里装）

1. 打开模拟器里的**应用宝**，搜索并安装一个**规则库已覆盖**的热门 App
   （见 `docs/Top100-热门应用清单.md`，如微博、抖音、百度网盘等）。
2. 启动该 App，观察开屏广告是否被自动跳过。
3. 如未命中：进入李跳跳「应用管理」确认该 App **已启用**，或用 autojs 抓取节点信息后补规则。

---

## 如何确认「真的跳过了」

**方式 A：看首页计数**
打开李跳跳首页，「已为你跳过 N 次」会增长。

**方式 B：看数据库日志（最可靠）**
```bash
adb shell "run-as hello.litiaotiao.app sqlite3 databases/litiaotiao.db \
  \"SELECT id,rule_type,package,trigger_text,action_kind,action_target,created_at FROM skip_logs ORDER BY id DESC LIMIT 10\""
```
- `rule_type`：`keyword`（开屏）/`popup`（弹窗）/`mini_program`（小程序兜底）
- `package`：是哪个应用
- `action_target`：实际被点击的控件 id

**方式 C：Web 工作台模拟器**
启动 `LiTiaotiao-Replica` 后访问 `http://127.0.0.1:8000` → 模拟器，粘贴节点树即可离线验证规则是否命中。

---

## 实测结果（2026-10-24，Android 14 模拟器）

```
skip_logs:
  id=25  keyword | hello.litiaotiao.testapp | 跳过广告 | NODE | ...:id/btnSkip
  id=26  popup   | hello.litiaotiao.testapp | 以后再说 | NODE | android:id/button2
```

✅ 开屏广告跳过生效；✅ 更新弹窗跳过生效。

> 注：应用宝在该模拟器环境下不展现开屏广告（仅隐私协议页），因此真机验证使用测试 App 完成。
